# 포트폴리오 편집 가이드

`content.js`를 VS Code 같은 텍스트 편집기로 열어 수정하고 저장한 후, `index.html`을 연 브라우저를 새로고침하세요. 별도 빌드는 필요하지 않습니다. 현재 내용은 예시입니다.

## 어디를 수정하나요?

| 수정할 내용 | 파일과 항목 |
|---|---|
| 이름·제목·소개 | content.js → name, headline, bio |
| 기술별 역량 설명 | content.js → skills |
| 프로젝트 추가·삭제·순서 | content.js → projects |
| 프로젝트 기간·엔진 | 각 프로젝트 → period, engine |
| 대표 이미지·영상·저장소 | 각 프로젝트 → image, videoUrl, githubUrl |
| 프로젝트별 기술 태그 | 각 프로젝트 → stack |
| 구현 요약·상세·고민 | 각 프로젝트 → implementations |
| 기본 펼침 상태 | 각 구현 → featured |
| 자격증·경력 | certifications, experience |
| 섹션별 색상 | theme.css |

## 구현 내용 추가 예시

다음 객체를 원하는 프로젝트의 `implementations: [ ... ]` 안에 넣습니다. 기존 항목 뒤에 추가할 때는 두 객체 사이에 쉼표를 넣으세요. 별도의 구현 폴더나 HTML 수정은 필요 없습니다.

```js
{
  "title": "데이터 기반 무기 시스템",
  "summary": "데이터 교체로 무기 종류를 추가할 수 있도록 구성했습니다.",
  "featured": true,
  "blocks": [
    { "title": "구현 내용", "text": "구현한 기능과 동작 방식을 작성합니다." },
    { "title": "설계 고민과 선택", "text": "어떤 상황에서 무엇을 비교했고, 왜 선택했는지 작성합니다." },
    { "title": "결과와 한계", "text": "효과와 남은 문제, 개선 방향을 작성합니다." }
  ],
  "tags": ["C++", "Data Asset"]
}
```

`featured: true`는 기본 펼침, `false`는 기본 접힘입니다. 생략해도 접힌 상태입니다. 방문자는 어떤 항목이든 다시 접거나 펼칠 수 있습니다. 대표 구현을 위에 보여주려면 배열의 맨 앞으로 옮기세요. 설정만으로 순서가 바뀌지는 않습니다.

## 상세 이미지·영상·코드

구현 객체에서 `blocks`와 같은 단계에 필요한 항목을 추가하세요. 상세 본문 뒤에 표시됩니다. 사용하지 않는 항목은 생략하면 됩니다.

```js
"image": "assets/combat.jpg",
"imageAlt": "스킬을 사용하는 플레이 화면",
"video": "assets/combat.mp4",
"code": "void Example() {\n  // 핵심 코드\n}"
```

`video`는 직접 재생 가능한 영상 파일 경로입니다. YouTube 페이지 주소는 프로젝트의 `videoUrl`에 입력하세요. 파일 경로에는 역슬래시 대신 `/`를 사용합니다.

## 입력 시 주의할 기호

- 문자열은 큰따옴표로 감싸세요. 문장 속 큰따옴표는 `\"`로 입력합니다.
- 문장 내 줄바꿈은 `\n`으로 작성합니다.
- `true`와 `false`에는 따옴표를 붙이지 않습니다.
- `//`로 시작하는 줄은 편집 설명이며 웹페이지에 표시되지 않습니다.
- 수정 후 내용이 보이지 않으면 쉼표·따옴표·괄호 누락을 먼저 확인하세요.

## 색상 수정

`theme.css`는 `소개`, `기술`, `프로젝트`, `자격증`, `경력`별로 구분되어 있습니다. `bg`는 배경색, `text`는 본문색, `accent`는 강조색입니다. `#222d34` 같은 색상 값만 바꾸고 세미콜론은 유지하세요.
