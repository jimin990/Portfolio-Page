# 포트폴리오 프로토타입

`index.html`을 브라우저에서 열면 바로 볼 수 있습니다. 빌드나 설치는 필요하지 않습니다.

## 내용 수정

- `content.js`: 이름, 소개, 기술 목록, 프로젝트, 구현 설명을 수정합니다. 현재 모든 프로젝트 내용은 예시입니다.
- `theme.css`: 소개 / 기술 / 프로젝트의 배경색·글자색·강조색을 각각 수정합니다.
- `assets/`: 프로젝트 이미지나 영상 파일을 넣습니다. `content.js`의 경로는 `assets/my-project.jpg`처럼 작성합니다.
- `style.css`: 간격, 글자 크기, 사이드바 너비 등 레이아웃을 수정합니다.

프로젝트 객체를 복사하면 새 프로젝트가 생깁니다. `id`는 영문으로 중복되지 않게 지정하세요. 구현은 `implementations` 목록에 추가합니다. `blocks`의 각 항목에는 `title`과 `text`를 넣습니다. 선택 항목으로 `image`, `imageAlt`, `video`(로컬 mp4 경로), `code`도 사용할 수 있습니다.

`videoUrl`과 `githubUrl`에는 실제 https 주소를 넣습니다. 빈 주소는 프로토타입에서 ‘준비 중’ 버튼으로 표시됩니다. 대표 이미지는 직접 만든 자리표시자이며 실제 게임 화면이 아닙니다.

## GitHub Pages

이 폴더 안의 파일을 구조 그대로 저장소의 게시 폴더에 넣으면 됩니다. 상대 경로를 사용하므로 github.io의 루트와 하위 프로젝트 경로에서 모두 사용할 수 있습니다. 현재 버전은 로컬 프로토타입이며 온라인으로 배포하지 않았습니다.

## 디자인

고정 사이드바, 섹션별 이동과 현재 위치 표시, 사각 기술 태그, 여러 항목을 동시에 펼칠 수 있는 구현 목록을 제공합니다. 모바일에서는 메뉴가 상단으로 바뀝니다. 시스템의 동작 줄이기 설정도 반영합니다.

## 추가된 편집 항목

- 프로젝트의 `name`과 `id`를 기준으로 사이드바 하위 메뉴가 자동 생성됩니다.
- 프로젝트의 `period`에는 기간, `engine`에는 엔진 이름과 버전을 입력합니다. 빈 값은 화면에서 생략합니다.
- `skills`의 `title`은 개발 영역, `description`은 할 수 있는 일, `detail`은 구체적인 활용 방법입니다. 현재 문장은 예시이므로 실제 경험에 맞게 수정하세요.

## 자격증과 추가 경력

`content.js`의 `certifications` 배열에 자격증(`name`, `issuer`, `date`, `description`)을, `experience` 배열에 경력(`organization`, `role`, `period`, `description`)을 추가합니다. 게임업계와 관계없는 경력도 작성할 수 있습니다. 자격증과 경력은 별도 섹션입니다. 색상은 `theme.css`의 `--certifications-*`와 `--experience-*`에서 각각 변경합니다.

프로젝트의 `period`와 `engine`은 소개 영역의 프로젝트 요약과 프로젝트 상세 소개에 함께 표시됩니다. 프로젝트별 `stack` 배열은 각 프로젝트의 독립된 ‘기술 스택’ 구역에 표시됩니다.


## 편집 도움말

자세한 복사·붙여넣기 예시는 `편집가이드.md`를 확인하세요. `content.js`는 항목별 한글 주석과 읽기 쉬운 들여쓰기를 제공합니다. 구현의 `featured`를 `true`로 바꾸면 처음부터 펼쳐집니다. 기존 접힘 상태는 유지했습니다.
